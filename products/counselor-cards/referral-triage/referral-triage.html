STEP 1 — ASSESS URGENCY

Every referral lands in exactly one lane

🔴 SEE TODAY

  • Suicidal statements or self-harm
  • Abuse/neglect disclosure
  • Active crisis (panic attack, uncontrollable crying)
  • Threat to harm others
  • Student not picked up / abandoned
→ Pull the student immediately. Follow crisis protocol.

🟡 SEE THIS WEEK

  • Sudden behavior change
  • Frequent tearfulness
  • Social isolation (new pattern)
  • Declining grades (rapid drop)
  • Bullying report
  • Parent request for counseling
→ Schedule within 48 hours. Observe in classroom first if possible.

🟢 SCHEDULE WHEN READY

  • Social skills concern
  • Mild anxiety (test worry, new situations)
  • Friendship difficulty
  • New student adjustment
  • Academic planning
  • Self-referral for "someone to talk to"
→ Add to caseload. Schedule within 1–2 weeks. Consider group placement.

STEP 2 — CHECK FLAGS  ·  STEP 4 — DOCUMENT

Before the first session · After every referral

🚩 BEFORE YOUR FIRST SESSION, CHECK:

Is this student SPED? → Coordinate with the SPED teacher. Document in IEP notes.
Is this student 504? → Review accommodations. May need a plan update.
Is this student on a BIP? → Read the plan. Your sessions should align.
Has this student been referred before? → Pull prior notes. Look for patterns.
Is there a custody issue? → Check who has pick-up rights. Be careful with parent contact.
Is there a language barrier? → Arrange an interpreter if needed.

📋 EVERY REFERRAL GETS:

  • Date received, source (teacher / parent / self / admin)
  • Concern type and urgency level
  • Action taken and date of first contact
  • Parent notification (date, method, response)
  • Follow-up plan
⚠️ "If you didn't document it, it didn't happen."
